# 고척스카이돔 3D 좌석 시야 시뮬레이터

좌석을 고르면 그 자리에서 보이는 그라운드를 3D로 보여주는 정적 웹앱입니다.
구역 선택 → 좌석 선택 → 1인칭 시야 순서로 카메라가 이동합니다.

## 실행

빌드 과정이 없습니다. 이 폴더를 정적 서버로 열면 됩니다.

```bash
cd gocheok-dome-3d
python3 -m http.server 8000   # http://localhost:8000
```

Vercel, Netlify, GitHub Pages 등 정적 호스팅에 이 폴더를 그대로 올리면 서비스할 수 있습니다.
three.js는 `vendor/`에 포함되어 있어 외부 CDN이 필요 없습니다.

## 사용법

- 전체 보기: 드래그로 회전, 휠/핀치로 확대, 구역을 누르면 그 구역으로 이동
- 구역 보기: 좌석을 누르면 그 자리의 시야로 이동
- 시야 보기: 드래그로 둘러보기, 휠/핀치로 확대, ←/→ 키로 옆자리, Esc로 뒤로
- 왼쪽 패널에서 구역·열·번호를 직접 골라 이동할 수 있고, 등급을 눌러 필터링할 수 있습니다
- 시야 화면의 주소(`#seat=구역/열/번호`)를 공유하면 같은 자리 시야가 열립니다

## 데이터 근거와 한계

실시설 설계 도면(CAD)은 공개되어 있지 않아, 공개 제원에 맞춰 형상을 만들고 나머지는 추정했습니다.

| 항목 | 값 | 근거 |
|---|---|---|
| 좌·우 폴 / 중앙 펜스 | 99m / 122m | 서울시 보도자료 |
| 외야 펜스 높이 | 4m | 서울시 보도자료 |
| 지붕 최고 높이 | 67.59m | 서울시 보도자료 |
| 중앙 전광판 | 22.4 × 7.68m | 서울시설공단 |
| 쌍둥이 전광판 | 28.32 × 12m | 언론 보도(2017) |
| 구역 번호 | 1층 101~132, 2층 201~222, 3층 301~334, 4층 401~435, T/R.d | 서울시설공단 좌석배치도 설명 |
| 좌석 수 | 모델 16,758석 (공식 16,744석) | 구단 공식 좌석수에 맞춰 보정 |
| 요금 | R.d-club·테이블·버건디·다크버건디는 구단 공지, 3층·4층·외야는 미검증 | 화면에 `*` 표시 |

추정한 부분: 관람석의 깊이·경사·층 높이, 파울 지역 폭, 구역별 각도 경계, 열/번호 배정,
외야 구역 번호 방향, 지붕·외벽 형상. 실제 좌석과 열·번호가 일치하지 않으며,
난간·기둥 등 시야 방해 요소는 반영되어 있지 않습니다.

치수와 구역은 `src/data.js`에서 고칠 수 있습니다. 실측 도면이나 좌석 배치표가 있으면 그 값으로 바꾸면 됩니다.

## 구조

- `index.html` — 화면 구성과 스타일
- `src/data.js` — 제원, 층(tier) 단면, 구역·등급·요금
- `src/stadium.js` — 그라운드·관람석·지붕·좌석 생성
- `src/main.js` — 카메라 이동, 좌석 선택, UI
