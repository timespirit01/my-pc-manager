# 고척스카이돔 3D 좌석 시야 시뮬레이터

좌석을 고르면 그 자리에서 보이는 그라운드를 3D로 보여주는 정적 웹앱입니다.
구역 선택 → 좌석 선택 → 1인칭 시야 순서로 카메라가 이동합니다.

## 실행

빌드 과정이 없습니다. 이 폴더를 정적 서버로 열면 됩니다.

```bash
cd gocheok-dome-3d
python3 -m http.server 8000   # http://localhost:8000
```

Vercel, Netlify, GitHub Pages 등 정적 호스팅에 이 폴더를 그대로 올리면 서비스할 수 있습니다.
three.js는 `vendor/`에 포함되어 있어 외부 CDN이 필요 없습니다.

## 사용법

- 전체 보기: 드래그로 회전, 휠/핀치로 확대, 구역을 누르면 그 구역으로 이동. 구역에 마우스를 올리면 그 구역 시야 미리보기가 뜹니다
- 구역 보기: 열 번호가 표시된 정면 좌석 배치도. 좌석을 누르면 그 자리의 시야로 이동, 휠/핀치로 확대
- 구역·시야 화면 공통: 상단의 ◀ ▶ 로 옆 구역 이동, 경로(전체 › 구역 › 좌석)를 눌러 되돌아가기, 미니맵을 눌러 다른 구역으로 이동
- 좌석 배치도: 상단 "배치도" 버튼. 층을 고르고 구역을 누르면 확대되며, 번호가 적힌 좌석을 누르면 그 자리 시야로 이동
- 시야 보기: 드래그로 둘러보기, 휠/핀치로 확대, 옆자리·앞뒤 열 버튼(또는 ←/→ 키)으로 이동, ↻ 로 자동 둘러보기, Esc로 뒤로
- 행사 모드: "야구 / 콘서트" 전환. 콘서트 모드의 무대는 가상 배치입니다
- 왼쪽 패널에서 구역·열·번호를 직접 골라 이동할 수 있고, 등급을 눌러 필터링할 수 있습니다
- 시야 화면의 주소(`#seat=구역/열/번호`)를 공유하면 같은 자리 시야가 열립니다

## 현실감 표현

좌석 시야 화면에는 다음 요소가 들어갑니다. 모두 실시간 3D로 그리며, 실제 사진이나 영상은 쓰지 않습니다.

- 정적 그림자, 환경 반사, 블룸(조명·전광판 번짐), 비네트·필름 그레인, 실내 헤이즈
- 접이식 좌석 형태, 난간, 백스톱 그물망, 펜스·벽 광고판, 띠 전광판, 지붕 조명 뱅크
- 관중(좌석의 약 60%, 모바일은 약 40%)과 선수·심판 모델. 관중은 시야 화면에서 켜고 끌 수 있습니다
- 광고판 문구와 전광판 내용, 관중·선수 배치는 가상의 것입니다

## 실제 360° 투어

화면 상단의 "실제 360° 투어" 버튼은 공개된 고척 스카이돔 가상투어(Cupix)를 새 창으로 엽니다.
투어의 사진은 이 앱에 포함하지 않았습니다. 사진을 앱 안에 넣으려면 권리자의 허락이 필요합니다.

## Blender 에셋

`assets/` 의 모델은 `tools/blender/` 스크립트로 Blender에서 만든 것입니다. 불러오기에 실패하면 앱은 예전의 절차적 모델로 대신 그립니다.

| 파일 | 내용 |
|---|---|
| `seat_hi.glb` / `seat_lo.glb` | 접이식 관람석 (곡면 등받이·팔걸이·다리). 보고 있는 구역 주변 38m만 고품질 |
| `roof_truss.glb` | 지붕 바깥 띠의 입체 철골 트러스와 막 구간 아치 |
| `players.glb` | 선수 자세 4종 (서기·수비 준비·포수·타자). 재질 이름으로 팀 색을 입힘 |
| `stands.glb` | 스탠드 형상 (조명용 두 번째 UV 포함) |
| `bake/*` | Cycles로 구운 조명: 스탠드·그라운드 라이트맵, 펜스·벽·트러스 정점 조명, 좌석별 밝기 |

다시 만드는 순서 (관람석 형상을 `src/data.js` 에서 바꿨다면 1~3 모두 다시 실행):

```bash
pip install bpy==5.3.0 playwright          # Blender 파이썬 모듈
python3 -m http.server 8765 &              # gocheok-dome-3d 폴더에서
node tools/export_scene.cjs http://localhost:8765/ /tmp/gd        # 1. 형상·좌석 위치 내보내기
python tools/blender/build_assets.py /tmp/gd/scene.json assets     # 2. 좌석·트러스·선수
python tools/blender/bake_stands.py /tmp/gd assets /tmp/st 1024 16 && cp /tmp/st/stands.glb assets/  # 3. 스탠드에 조명용 UV 추가
python tools/blender/seat_ao.py assets                                 # 4. 좌석 모델에 주변 그림자
node tools/export_bake.cjs http://localhost:8765/ /tmp/gb              # 5. 조명 굽기용 장면 내보내기
python tools/blender/bake_lighting.py preview /tmp/gb assets /tmp/p.png 9186 32   # (선택) 좌석 시점 Cycles 렌더로 조명 확인
python tools/blender/bake_lighting.py bake /tmp/gb assets assets/bake 2048 192    # 6. 조명 굽기 (4코어 CPU 약 1시간)
python tools/blender/preview.py assets /tmp/pv                     # (선택) Cycles 미리보기 렌더
```

### 조명

구운 조명은 낮 경기 기준입니다. 지붕 조명등 70개(면광원), 지붕 막을 통과하는 빛, 전광판·띠 LED의 빛과 그 반사광을 계산했습니다.
구운 조명이 있으면 실시간 그림자 계산을 끄므로 이전보다 가볍습니다. 선수·관중만 실시간 조명을 씁니다.
조명 세기는 `bake_lighting.py` 맨 위 `LAMP_W, MEMBRANE, BOARD` 로 바꿉니다. 콘서트 모드는 노출을 낮춰 어둡게 보여 줄 뿐, 조명을 다시 굽지는 않습니다.
주소 끝에 `?nobake=1` 을 붙이면 굽기 전 실시간 조명 화면을 볼 수 있습니다.

## 가상투어 대조

공개 가상투어(서울시설공단, Cupix)의 촬영 지점 세 곳에서 사진 속 기준점(홈·마운드·베이스·폴·펜스)으로 카메라 위치와 화각을 역산하고,
같은 카메라로 모델을 찍어 사진과 겹쳐 맞췄습니다.

| 지점 | 역산한 카메라 | 반영한 것 |
|---|---|---|
| 포수 뒤 (다이아몬드석) | 홈 뒤 14.2m, 높이 5m | 백스톱 9.5m, 홈 옆 벽 14m, 파울 지역 바닥 |
| 내야 상층 1루측 | 경계에서 21.8m, 높이 19.3m | 4층 위치·높이 일치 확인, 3·4층 끝 안내 화면·간판 |
| 외야 하층 중앙 | 중견 펜스 뒤 1.8m, 높이 7.9m | 외야 워닝트랙 5.5m, 외야석 범위(폴 쪽 좌석 없음), 쌍둥이 전광판 높이 |

전광판·띠 LED는 가상투어처럼 꺼진 상태로, 펜스는 광고 없는 패드로 그렸습니다.

## 데이터 근거와 한계

실시설 설계 도면(CAD)은 공개되어 있지 않아, 공개 제원에 맞춰 형상을 만들고 나머지는 추정했습니다.

| 항목 | 값 | 근거 |
|---|---|---|
| 좌·우 폴 / 중앙 펜스 | 99m / 122m | 서울시 보도자료 |
| 외야 펜스 높이 | 4m | 서울시 보도자료 |
| 지붕 최고 높이 | 67.59m | 서울시 보도자료 |
| 중앙 전광판 | 22.4 × 7.68m | 서울시설공단 |
| 쌍둥이 전광판 | 28.32 × 12m | 언론 보도(2017) |
| 구역 번호 | 1층 101~132, 2층 201~222, 3층 301~334, 4층 401~435, T/R.d | 서울시설공단 좌석배치도 설명 |
| 좌석 수 | 모델 약 15,800석 (공식 16,744석) | 추정 배치라 실제와 차이가 있음 |
| 색·형태 | 붉은 파울 지역, 지붕 중앙 막과 바깥 철골, 좌석 색, 쌍둥이 전광판 위치, 상단 외야 범위 | 공개 가상투어 화면을 눈으로 참고 (이미지는 복사하지 않음) |
| 요금 | R.d-club·테이블·버건디·다크버건디는 구단 공지, 3층·4층·외야는 미검증 | 화면에 `*` 표시 |

추정한 부분: 관람석의 깊이·경사·층 높이, 파울 지역 폭, 구역별 각도 경계, 열/번호 배정,
외야 구역 번호 방향, 지붕·외벽 형상. 실제 좌석과 열·번호가 일치하지 않으며,
난간·기둥 등 시야 방해 요소는 반영되어 있지 않습니다.

치수와 구역은 `src/data.js`에서 고칠 수 있습니다. 실측 도면이나 좌석 배치표가 있으면 그 값으로 바꾸면 됩니다.

## 구조

- `index.html` — 화면 구성과 스타일
- `src/data.js` — 제원, 층(tier) 단면, 구역·등급·요금
- `src/stadium.js` — 그라운드·관람석·지붕·좌석 생성
- `src/main.js` — 카메라 이동, 좌석 선택, UI
