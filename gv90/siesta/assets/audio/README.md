# 무드 음원

이 폴더는 비어 있어도 콘텐츠가 정상 재생된다.
음원이 없으면 화면과 조명·커튼 제어는 그대로 동작하고, 운영자 디버그
오버레이에 "음원을 찾지 못했습니다" 만 뜬다.

제안서 48p 기준 길이로 아래 파일명으로 넣는다.

| 파일 | 모드 | 제안서 길이 |
|---|---|---|
| `delight.mp3` | DELIGHT MODE | 03:07 |
| `calming.mp3` | CALMING MODE | 03:10 |
| `cozy.mp3` | COZY MODE | 04:09 |
| `siesta.mp3` | SIESTA | 02:30 |

경로를 바꾸려면 `config.json` 의 `modes[].room.audio.src` 를 수정한다.

재생은 브라우저가 PC 오디오 출력으로 내보내고, 그 출력이 **BeoLab 50** 에 물린다.
페이드 인/아웃과 볼륨은 `config.json` 의 `hardware.audio` 에 있다.

음원은 반복 재생된다. 구동 화면이 끝나 선택 화면으로 돌아와도 계속 흐르고,
다른 모드를 고르거나 인트로로 돌아갈 때 페이드아웃된다.
