# 음원 스템

이 폴더는 비어 있어도 콘텐츠가 정상 재생된다.
사운드 익스피어리언스는 전 구간이 Web Audio 실시간 합성이라
음원 파일 없이도 소리가 난다.

실제 음원이 준비되면 아래 파일명으로 넣는다. `config.json` 의
`audio.stems` 에 등록된 파일만 읽고, 없으면 조용히 합성음으로 되돌아간다.

| 파일 | 용도 | 권장 |
|---|---|---|
| `city-noise.mp3` | CLEAR 구간의 도시 소음 베드 | 30초 이상, 루프 가능, 48kHz |
| `atmos-demo.mp3` | EXPAND 구간의 애트모스 데모 | 30초 이상, 스테레오 다운믹스 |

경로를 바꾸거나 스템을 추가하려면 `config.json` 의 `audio.stems` 를 수정한다.
