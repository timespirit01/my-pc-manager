# 동시통역 앱 — 통역 엔진 추가 검토 (GPT vs Gemini)

작성일 2026-11-24 · 설계 문서(`261124_동시통역앱_설계.md`)의 보충 자료

**결론: Gemini 3.5 Live Translate를 그대로 주 엔진으로 쓴다.** 속도는 Gemini가 앞서는 시험이 더 많고, 비용은 두 엔진이 거의 같다. 다만 한국어로 두 엔진을 직접 비교한 자료가 없으므로, 0단계에서 같은 한국어 음성으로 둘을 직접 재 보고 확정한다.

모든 수치는 웹 검색으로 모은 것이다. 공식 가격 페이지는 이 세션에서 열지 못했고, 가격 대부분은 제3자 자료에서 왔다.

---

## 1. 후보 비교

| | Gemini 3.5 Live Translate | GPT-Realtime-Translate | GPT-Live-1.1 | GPT-Realtime-2.1 (mini) |
|---|---|---|---|---|
| 성격 | 통역 전용 | 통역 전용 | 범용 음성 대화 | 범용 음성 대화 |
| 분당 비용 | 약 $0.037 (입력 $0.005 + 출력 $0.032) | $0.034 (입력 음성 기준) | $0.05 + 뒷단 모델 비용 별도 | $0.05~0.15 (mini $0.02~0.05) |
| 지연 (말 끝 → 통역 확정) | 중앙값 1.5~1.9초 / 3.1초 | 중앙값 2.7~3.3초 / 3.8초 | 자료 없음 | 자료 없음 |
| 출력 언어 | 70개 이상 | 13개 | — | — |
| 한국어 | 지원 (공식 언어표) | 출력 13개에 포함 (제3자 자료, 공식 미확인) | — | — |
| 입력 언어 자동 감지 | 지원 | 미확인 | — | — |
| 상태 | 미리보기 | 출시 (2026-05) | 출시 (2026-11) | 출시 |

범용 음성 모델 두 가지는 탈락이다. 통역을 지시문으로 시키는 방식이라 질문을 통역하지 않고 직접 대답해 버릴 위험이 있고, 비용도 통역 전용 모델보다 높다.

## 2. 속도

지연을 잰 시험 세 건 중 두 건에서 Gemini가 빨랐다.

| 시험 | Gemini 3.5 Live Translate | GPT-Realtime-Translate |
|---|---|---|
| LiveLingo (영→스페인어 / 영→일본어) | 1.5초 / 1.9초 | 2.7초 / 3.3초 |
| 2026년 6월 벤치마크 | 중앙값 3.1초 (최악 13.9초) | 중앙값 3.8초 (말이 빽빽하면 20.3초까지) |
| 2026년 5월 벤치마크 | 대상 아님 (Gemini 3.5 출시 전) | 5개 중 가장 빠름 (중앙값 5.4초) |

- 시험마다 재는 방법이 달라 절대값은 서로 비교할 수 없다. 같은 시험 안의 순서만 의미가 있다.
- LiveLingo는 자사 통역 제품을 파는 회사라 이해관계가 있다.
- "말 시작 → 첫 통역 음성"은 Gemini 약 2.9초(LiveLingo), "말 끝 → 통역 음성 시작"은 0.3~0.5초라는 개발자 한 명의 측정이 있으나 검증되지 않았다.
- **한국어로 두 엔진을 직접 비교한 시험은 찾지 못했다.** 한국어 번역 품질 벤치마크에 Gemini는 올라 있지만(오류 점수 약 2.99, 낮을수록 좋음) GPT 항목은 없다.
- 완료 기준은 "말을 마친 뒤 1초 안에 통역 음성 시작"으로 확정됐다(2026-11-24). 공개 자료로는 달성 여부를 판단할 수 없어 0단계에서 실측한다.

## 3. 비용

10분 동안 누군가 계속 말한다고 가정한 계산이다(내 계산).

| 방식 | Gemini | GPT |
|---|---|---|
| 버튼 눌러 말하기 (한 번에 세션 하나만 음성 수신) | 약 $0.37 | 약 $0.34 |
| 버튼 없는 자동 대화 (세션 2개가 동시에 수신) | 약 $0.42 | 약 $0.68 |

- 버튼 방식에서는 차이가 10분에 3센트라 비용으로는 엔진을 가를 수 없다.
- 자동 대화에서는 Gemini가 유리하다. Gemini는 입력이 싸고 출력이 비싼 구조인데, 두 세션 중 실제로 통역 음성을 내는 것은 하나뿐이다. GPT는 입력 음성 시간으로 과금해서 세션이 둘이면 비용도 두 배가 된다(과금 구조에서 추론한 값, 실측 필요).

## 4. 검토 중 새로 알게 된 것 — 버튼 없는 대화가 가능해 보인다

Gemini 통역 모델은 입력 언어를 자동으로 감지하고, `echoTargetLanguage`를 끄면 **입력이 이미 목표 언어일 때 침묵한다.** 이 성질을 쓰면 세션 두 개를 동시에 열어 버튼 없이 양방향 통역을 할 수 있다.

```
마이크 ─┬→ 세션 A (목표: 영어)   한국어가 들리면 영어로 통역, 영어가 들리면 침묵
        └→ 세션 B (목표: 한국어) 영어가 들리면 한국어로 통역, 한국어가 들리면 침묵
```

설계 문서는 이 기능을 4단계(선택 확장)로 미뤄 두었는데, 0단계에서 동작이 확인되면 1단계 기본 방식으로 올릴 수 있다. 남는 위험은 폰 스피커에서 나온 통역 음성을 마이크가 다시 주워 반대 세션이 되받아 통역하는 것이다. 통역 음성 재생 중에는 마이크 전송을 멈추는 방식으로 막는다.

## 5. GPT와 Gemini를 섞어 쓰는 방식

음성 인식, 번역, 음성 합성을 서로 다른 서비스로 이어 붙이는 방식이다(예: 한쪽으로 받아쓰고 다른 쪽으로 번역). 단계마다 지연이 더해지므로 음성을 바로 음성으로 바꾸는 통역 전용 모델보다 느려진다. 통역 전용 모델이 이미 분당 3~4센트라 비용 이점도 기대하기 어렵다. 단계별 단가는 이번 검색에서 확인하지 못했다. 권하지 않는다.

## 6. 설계 문서에 반영할 변경 (승인 후 수정)

| 위치 | 현재 | 변경안 |
|---|---|---|
| 3-3 말하는 방식 | 1차 버튼, 자동 감지는 4단계 | 0단계에서 세션 2개 방식이 확인되면 자동 대화를 1차 기본으로, 버튼은 소음 환경용 대체 수단으로 |
| 3-4 엔진 사양 | 음성 형식·설정 필드·요금 [미확인] | 출력 16비트 PCM 24kHz 모노, 입력은 100ms 단위 전송, 설정 필드 `targetLanguageCode`·`echoTargetLanguage`, 요금 약 $0.037/분 (입력 샘플레이트는 여전히 [미확인]) |
| 3-2 통역 세션 모듈 | Gemini 전용 | 엔진을 갈아 끼울 수 있는 얇은 접속 계층으로 분리 (GPT 대체 가능) |
| 7. 0단계 | Gemini 한 방향 시연 | 같은 한국어·영어 음성 10개로 Gemini와 GPT의 지연·번역 품질을 직접 측정해 엔진 확정 |
| 1. 완료 기준 1·2 | 2초 안에 통역 음성 시작 | 0단계 실측값을 보고 재설정 |
| 10. 착수 전 필요한 것 | Gemini 키 | 비교 측정을 하려면 OpenAI API 키도 필요 (없으면 Gemini 단독으로 진행) |
