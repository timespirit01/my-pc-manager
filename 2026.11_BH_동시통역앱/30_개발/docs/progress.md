- **완성**: 모바일 웹앱 전체 (결과 위치: `../src/`)
  - 2분할 화면(상대 쪽 180° 회전), 처음 안내, 언어 선택(10개), 설정(대화 방식·글자 크기·응답 속도 표시), 어두운 화면
  - 자동 대화(세션 2개 동시 수신)와 눌러서 말하기, 되울림 차단, 다시 듣기
  - 통역 엔진 접속(Gemini Live API 통역 모델), 임시 토큰 서버, 접속 암호
  - 자동 재연결(연결 시간 한도, 끊김, 인터넷 차단), 오류 안내
  - 자동 검사 27개 + 15분 연속 대화 검사, 화면 캡처 9장(`screens/`)
- **진행 중**: 없음
- **남은 문제**
  - 실제 통역 엔진으로 한 번도 돌려 보지 못함. 연결된 Gemini API 키가 401(`API_KEY_SERVICE_BLOCKED`)로 거절됨. 완료 기준 1·2(1초)와 통역 품질은 미확인
  - 실제 휴대폰(Android Chrome, iPhone Safari)에서 확인하지 못함
  - 배포하지 않음
  - 상대 쪽 화면 문안 10개 언어는 원어민 검수를 받지 않음
- **결과에 영향을 준 가정**
  - 내 언어는 한국어 고정, 상대 언어 10개 (사용자 확정 아님)
  - 코드 위치는 `my-pc-manager` 저장소의 `2026.11_BH_동시통역앱/30_개발/src` (사용자 확정 아님)
  - 마이크 입력은 16kHz 16비트 PCM으로 보냄. 공식 문서로 확인하지 못한 값
  - 엔진이 입력 받아쓰기에 언어 코드를 주면 그것으로, 안 주면 "통역 음성을 낸 세션의 받아쓰기만 표시"로 중복을 막음. 실제 엔진이 어느 쪽인지 모름
  - 엔진이 한 마디의 끝(`turnComplete`)을 알려 주지 않을 경우에 대비해 1.5초 동안 새 내용이 없으면 끝난 것으로 처리
  - 설계→계획 문서→착수 순서였으나, 사용자가 설계 승인과 함께 "개발 진행"을 지시해 별도 계획 문서 없이 구현함. 검사 항목은 `checks.md`
- **실패한 시도**
  - 공식 문서 사이트(ai.google.dev) 접근: 이 세션의 네트워크에서 차단됨 → 공식 SDK(`@google/genai` 3.6.1) 소스에서 프로토콜을 읽는 것으로 대체. 문서 사이트 접근은 다시 시도하지 않음
  - 가짜 서버가 말의 첫 40ms 조각만으로 언어를 판정 → 소리가 조각 중간에 시작되면 영어를 한국어로 오판해 검사가 간헐적으로 실패. 첫 조각을 빼고 120ms를 모아 판정하도록 고침 (앱 결함 아님)
