## 1. 목적·사용자·완료 기준

**목적** — 휴대폰 한 대를 사이에 두고 외국인과 마주 보며, 각자 자기 언어로 말하고 듣는 대화를 가능하게 한다.

**사용자**
- 나(한국어 화자): 앱을 열고 상대 언어를 고른다.
- 상대(외국어 화자): 앱 설치나 가입 없이, 내 폰 화면의 자기 쪽 절반만 보고 말한다.

**결정된 사항**
- [확정] 사용 상황: 대면 대화
- [확정] 통역 엔진: 실시간 음성 AI
- [추정] 기본 언어 쌍은 한국어 ↔ 영어, 상대 언어는 목록에서 선택
- [추정] 사내·자체 건으로 보고 폴더명을 `2026.11_BH_동시통역앱`으로 잡음

**완료 기준** (수치는 [추정] — 검토 때 조정)

| # | 완료 기준 |
|---|---|
| 1 | 한국어로 말을 마친 뒤 2초 안에 상대 언어 음성이 나오기 시작한다 (10회 중 8회 이상) |
| 2 | 반대 방향(상대 언어 → 한국어)도 같은 기준을 만족한다 |
| 3 | 양쪽 화면에 원문과 번역문이 자막으로 나오고, 상대 쪽 화면은 180° 뒤집혀 보인다 |
| 4 | Android Chrome과 iPhone Safari 최신 버전에서 동작한다 |
| 5 | 15분 연속 대화 동안 사용자가 손대지 않아도 연결이 유지된다 |
| 6 | 네트워크가 끊기면 화면에 안내가 뜨고, 복구되면 5초 안에 다시 연결된다 |
| 7 | API 키가 브라우저로 내려가지 않는다 (브라우저 네트워크 기록에 키 문자열 없음) |
| 8 | 상대 언어를 5개 이상 중에서 고를 수 있다 |

## 2. 사용 조건

| 항목 | 내용 |
|---|---|
| 기기 | 휴대폰 1대 (세로 화면). 내장 마이크·스피커 사용 |
| 형태 | 설치 없는 모바일 웹앱. 홈 화면에 추가하면 앱처럼 실행 |
| 네트워크 | 인터넷 필수 (LTE/5G/Wi-Fi). 오프라인 통역은 범위 밖 |
| 주소 | HTTPS 필수 — 휴대폰 브라우저는 HTTPS에서만 마이크를 허용 |
| 소음 | 카페·거리·행사장 정도의 주변 소음을 가정 |
| 사용 시간 | 한 번에 수 분~30분 대화 |

## 3. 구성

### 3-1. 전체 흐름

```
[휴대폰 브라우저]
  마이크 → 음성 변환(PCM) ─┐
                            ├─ WebSocket ─→ [Gemini Live API · 통역 모델]
  스피커 ← 통역 음성 재생 ─┘                └→ 통역 음성 + 원문·번역 자막
        ↑
        │ ① 앱 시작 시 임시 토큰 요청 (암호 확인)
        ↓
[토큰 서버 — 함수 1개]  ← API 키는 여기에만 보관
```

음성은 브라우저에서 통역 모델로 직접 오간다. 우리 서버는 임시 토큰만 발급하므로 음성이 서버를 거치지 않아 지연이 짧고, 서버가 단순하다.

### 3-2. 모듈

| 모듈 | 역할 |
|---|---|
| 화면 (UI) | 위·아래 2분할. 위쪽은 상대용(180° 회전), 아래쪽은 내 쪽. 각 절반에 말하기 버튼, 자막, 상태 표시 |
| 음성 입력 | 마이크 권한 요청, 통역 모델이 받는 형식으로 변환해 전송 |
| 음성 출력 | 받은 통역 음성을 끊김 없이 이어서 재생. 다시 듣기 지원 |
| 통역 세션 | 통역 모델 연결·재연결·토큰 갱신. 방향별(한→외, 외→한) 세션 관리 |
| 대화 기록 | 원문·번역문을 화면에 쌓아 보여줌. 브라우저 메모리에만 보관 |
| 토큰 서버 | 암호를 확인하고 짧은 수명의 임시 토큰 발급 (엔드포인트 1개) |
| 설정 | 상대 언어, 글자 크기 |

### 3-3. 누가 말하는지 정하는 방식

폰 마이크가 하나라서 누가 말하는지 앱이 알아야 통역 방향이 정해진다.

- **1차: 탭해서 말하기** — 말하는 사람이 자기 쪽 버튼을 누르고 말한다. 시끄러운 곳에서도 방향이 틀리지 않고, 폰 스피커로 나간 통역 음성을 마이크가 다시 주워 재통역하는 문제를 막는다.
- **2차(선택): 자동 감지** — 버튼 없이 언어를 자동으로 구분. 통역 모델이 양방향 자동 감지를 지원하는지 [미확인]이라 1차 완성 후 판단한다.

### 3-4. 통역 엔진 사양

| 항목 | 내용 | 확인 상태 |
|---|---|---|
| 모델 | `gemini-3.5-live-translate-preview` — 음성 입력 → 통역 음성 + 자막, 70개 이상 언어 | 검색으로 확인. **미리보기(preview) 단계라 사양이 바뀔 수 있음** |
| 설정 | 목표 언어 지정, 에코 옵션 | 검색으로 확인 (세부 필드명은 [미확인]) |
| 인증 | 임시 토큰: 기본 수명 30분, 발급 후 1분 안에 세션 시작 | 검색으로 확인 (임시 토큰도 미리보기 단계) |
| 연결 유지 | 10분마다 세션 재개(sessionResumption)로 재연결 필요 | 검색으로 확인 |
| 음성 형식 | 입력·출력 샘플레이트와 인코딩 | [미확인] |
| 요금 | 사용량 과금 | 단가 [미확인] |

[미확인] 항목은 구현 0단계에서 공식 문서로 확정한다. 이 세션에서는 공식 문서 사이트(ai.google.dev) 접속이 막혀 있어 검색 결과로만 확인했다.

### 3-5. 기술 선택

- 프런트엔드: 프레임워크 없는 정적 웹페이지 (HTML·CSS·JavaScript). 화면이 하나뿐이라 프레임워크가 필요 없다.
- 토큰 서버: 서버리스 함수 1개.
- 배포: Vercel (정적 파일 + 함수, HTTPS 자동). [추정]
- 저장소 위치: `my-pc-manager` 저장소의 `2026.11_BH_동시통역앱/30_개발/` 아래. [추정] — 별도 저장소를 원하면 변경.

## 4. 교체 지점

코드를 고치지 않고 바꿀 수 있어야 하는 것은 설정 파일 한 곳(`config.js`)에 모은다.

- 언어 목록과 기본 언어 쌍
- 화면 문안 (버튼, 안내, 오류 메시지 — 한국어와 상대 언어 양쪽)
- 통역 모델 ID (미리보기 모델이 정식판으로 바뀔 때 대비)
- 재연결 주기, 지연 경고 기준

API 키와 접속 암호는 설정 파일이 아니라 배포 환경의 환경 변수에 둔다.

## 5. 장애 대응

| 상황 | 동작 |
|---|---|
| 마이크 권한 거부 | 권한 켜는 방법을 화면에 안내. 다시 시도 버튼 |
| 네트워크 끊김 | 양쪽 화면에 "연결 끊김" 표시 → 자동 재연결. 끊긴 동안 말한 내용은 통역되지 않았다고 표시 |
| 10분 세션 한도 | 사용자가 모르게 세션 재개. 말하는 도중이면 발화가 끝난 뒤 전환 |
| 토큰 만료 | 만료 전에 새 토큰을 미리 받아 교체 |
| 통역 지연 (3초 초과) | "통역 중…" 표시로 기다리라는 신호를 줌 |
| 음성 인식 실패·무음 | "다시 말씀해 주세요"를 해당 화자 언어로 표시 |
| 스피커 소리를 마이크가 다시 주움 | 통역 음성 재생 중에는 마이크 전송을 멈춤 |
| 요금 초과 위험 | 접속 암호로 외부인 사용 차단. 무입력 2분이면 세션 자동 종료 |

## 6. 확인 방법

- **자동 확인 (이 개발 환경에서 가능)**: 미리 녹음한 한국어·영어 음성 파일을 가짜 마이크 입력으로 넣어 브라우저를 구동하고, 발화 종료 시각과 통역 음성 시작 시각을 로그로 비교한다. 완료 기준 1·2·5·6·7을 이 방식으로 확인한다.
- **실기기 확인 (사용자 휴대폰 필요)**: Android Chrome, iPhone Safari에서 실제로 말해 본다. 완료 기준 3·4와 소음 환경 체감은 실기기로만 확인할 수 있다. 이 개발 환경에는 마이크와 휴대폰이 없다.
- **확인 못 한 항목**은 통과로 적지 않고 `미확인`으로 남긴다.

## 7. 단계

| 단계 | 내용 | 끝나면 볼 수 있는 것 |
|---|---|---|
| 0. 사전 확인 | API 키 정상화, 공식 문서로 음성 형식·설정 필드·요금 확정, 한 방향 통역 최소 시연 | "한국어 음성 파일 → 영어 음성" 1회 성공 기록 |
| 1. 핵심 기능 | 2분할 화면, 탭해서 말하기, 양방향 통역, 자막 | 한 폰에서 양방향 대화 |
| 2. 안정화 | 자동 재연결, 토큰 갱신, 오류 안내, 언어 선택, 대화 기록 | 15분 연속 대화 |
| 3. 배포 | HTTPS 배포, 접속 암호, 실기기 검증 | 휴대폰에서 주소로 접속해 사용 |
| 4. 선택 확장 | 자동 감지(버튼 없는 대화), 대화 기록 내보내기, 음성 교체 | 필요할 때 별도 결정 |

0단계에서 통역 모델이 기대대로 동작하지 않으면 멈추고 엔진을 다시 고른다.

## 9. 개인정보·비용

- 음성은 통역을 위해 Google 서버로 전송된다. 우리 서버에는 음성도 대화 내용도 저장하지 않는다.
- 대화 기록은 브라우저 메모리에만 있고 탭을 닫으면 사라진다.
- 상대에게 통역 앱 사용 사실을 알릴 수 있도록 상대 쪽 화면에 첫 안내 문구를 띄운다.
- 요금은 사용한 음성 시간만큼 나온다. 단가는 0단계에서 확인해 "10분 대화당 예상 비용"으로 보고한다.
